## Publishing website updates

Before committing a website update, run `./update-site-timestamp.ps1` with PowerShell and include the resulting HTML changes in the release. This refreshes the small site-wide footer timestamp on every tracked HTML page, including brochure archive pages. The displayed format is `Updated: MM/dd/yy - HH:mm PT` in Pacific time; the HTML time element includes the UTC offset. It records the website update time, not a visitor's current time or the revision date of an archived document. Check the GitHub Pages deployment after pushing.
